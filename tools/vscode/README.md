# Frege Diagrams for VS Code

Edit the figures of [frege-diagrams](https://github.com/fairflow/frege-diagrams)
inside VS Code: Frege-style formula trees and Kripke frame pictures, drawn by
Lean from the figure language.

Opening a figure file (`*.fgd`) shows the figure editor: the sketch, the
Frege view, the inspector and the text, as in the browser editor
(`tools/framedit/`). Saving goes through VS Code; *Reopen Editor With… → Text
Editor* shows the plain text.

The drawing is done by `framediag`, built by Lake in your workspace: the
workspace's `lakefile` requires frege-diagrams, and the extension runs
`lake build framediag` the first time if needed. The settings
`fregeDiagrams.framediagPath` and `fregeDiagrams.lakePath` override where the
programs are.

In a Lean file, *Edit figures* above each figure string
(`def NAME : String := r#"…"#`) opens the editor on that string beside the
Lean file; saving writes the string back and saves the Lean file.

The figure language is coloured in `.fgd` files and inside Lean figure
strings; parse errors and the checks of each figure are squiggles, with
their fixes as quick fixes. The grammars in `syntaxes/` are generated by
`python3 docs/tools/grammar.py --textmate tools/vscode/syntaxes`.

## Building and installing

```bash
cd tools/vscode
npm run package          # writes frege-diagrams.vsix
code --install-extension frege-diagrams.vsix
```

Then run *Developer: Reload Window* in **every** VS Code window that is
already open: VS Code does not start a newly installed extension (or a new
version) in open windows, and until it starts, Lean files show no *Edit
figures* link and `.fgd` files open as plain text.

`npm test` runs a smoke test of the message handling against a real
`framediag` (built with `lake build framediag` at the repository root).

`npm install` and then `npm run test:vscode` run the extension in a real VS
Code (downloaded by `@vscode/test-electron`, version 1.85.2, the oldest that
`engines` allows; `FD_VSCODE_VERSION` picks another). The window opens a plain
folder; a Lean file and a figure file of *another* Lake project are opened,
the *Edit figures* lens is pressed, and the test waits until the page in each
panel has received a drawing from `framediag`, with no error shown. On Linux
without a display, run it under `xvfb-run -a`; CI does. Locally it opens a VS
Code window for a few seconds.

For this test `activate` returns `{ status }`: every error shown to the user,
and per figure panel its file, its `framediag`, and how many drawings reached
the page.
